# Exterminadle
A daily guessing game. You're shown a quote from a Doctor Who episode: anything from 2005 onwards, Ninth Doctor through Fifteenth. You name the episode. Every wrong guess reveals another quote from the same episode, so the puzzle eases up as you go. Five quotes, five guesses, a new episode every day at midnight.
